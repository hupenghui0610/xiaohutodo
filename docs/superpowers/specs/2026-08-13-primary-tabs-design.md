# 一级功能 Tab 改造设计

## 背景与目标

当前主界面只有 To-do List 功能，顶部左侧显示“小胡同学To-do List”，右侧显示周时间切换栏。为了给后续“文档链接”功能预留一级入口，本次将顶部标题改造成一级 Tab 导航，在不改变现有视觉风格和待办业务逻辑的前提下，支持在“To-do List”和“文档链接”之间切换。

本版本只建立“文档链接”入口和占位视图，不实现文档链接的数据、表单、存储或管理能力。

## 界面设计

### 顶部导航

- 将主界面顶部左侧的“小胡同学To-do List”替换为两个一级 Tab：“To-do List”和“文档链接”。
- 两个 Tab 的字号统一为 18px，字重、间距和整体布局延续现有规范；两个 Tab 之间使用仅作视觉展示的 `|` 分隔符。
- 选中 Tab 使用现有蓝色强调色，并显示清晰的底部指示线；未选中 Tab 使用现有柔和文字色。
- Tab 的交互状态不得造成布局位移。
- 登录页标题“小胡同学To-do List”保持不变。

### To-do List 视图

- 默认选中“To-do List”。
- 原有无限期、周待办、日待办区域及其全部功能保持不变。
- 顶部右侧周时间切换栏只在该 Tab 下显示。

### 文档链接视图

- 选中“文档链接”后，隐藏 To-do List 的全部主体内容和顶部周时间切换栏。
- 主体区域显示一个沿用现有面板背景、边框、圆角和阴影规范的占位面板。
- 占位面板只显示“功能占位”文字，不增加图标、说明、按钮或数据交互。

### 公共区域

- 页脚右侧的当前账号、账号管理、修改密码和退出登录等账号功能在两个 Tab 下均保留。
- 页脚左侧的“无限期、周待办、日待办”图例属于 To-do List，只在 To-do List Tab 下显示；其他 Tab 下左侧暂时留空。
- Tab 切换不影响登录状态、待办数据或当前查看周。

## 交互与状态

- 页面初始化后始终默认进入“To-do List”。
- 当前 Tab 仅保存在页面运行时内存中，不写入本地存储，也不写入 URL；刷新页面后回到“To-do List”。
- 点击 Tab 时同步更新：选中样式、无障碍选中状态、对应内容面板显隐以及周时间切换栏显隐。
- To-do List 主体面板包含无限期、周待办、日待办三个完整区域；文档链接主体面板只包含“功能占位”。任何时刻只允许一个主体面板在视觉上显示。
- Tab 使用 `tablist`、`tab` 和 `tabpanel` 语义，选中项设置 `aria-selected="true"`，未选中项设置 `aria-selected="false"`。
- 键盘焦点位于 Tab 时，左右方向键在两个 Tab 之间移动并完成切换；Tab 键继续按正常文档顺序移动焦点。
- 不引入切换动画，避免增加与现有界面不一致的动效。

## 技术方案

- 保持当前单页架构，在 `index.html` 内增加 Tab 标记、两个内容面板和少量状态切换逻辑。
- 将现有待办主体整体作为 To-do List 面板；新增独立的文档链接占位面板。
- 周时间切换栏作为 To-do List 的关联控件，根据活动 Tab 显示或隐藏。
- 使用显式 CSS 规则 `.sections[hidden] { display: none; }` 保证 `hidden` 属性不被 `.sections { display: flex; }` 覆盖。
- 页脚左侧图例作为 To-do List 的关联区域，与周时间切换栏使用相同的活动 Tab 状态显示或隐藏；页脚右侧账号区域不参与 Tab 切换。
- 不拆分新页面，不增加路由、第三方依赖或新的持久化结构。
- 不修改现有待办渲染、保存、编辑、删除及周切换逻辑。

## 异常与兼容处理

- Tab 切换是纯客户端本地行为，不涉及网络请求，因此不新增加载或错误状态。
- 若 JavaScript 正常执行，显隐和无障碍状态始终由同一个切换函数统一更新，避免视觉状态与实际内容不一致。
- 保持现有响应式布局；窄屏时 Tab 可保持同一行并自然占用左侧空间，顶部容器沿用现有弹性布局能力。

## 测试与验收标准

自动化测试至少覆盖：

1. 页面包含两个一级 Tab，且默认选中“To-do List”。
2. 默认显示原有待办面板和周时间切换栏，隐藏文档链接占位面板。
3. 切换到“文档链接”后，显示“功能占位”，隐藏待办面板和周时间切换栏。
4. 切回“To-do List”后，恢复待办面板和周时间切换栏。
5. 隐藏面板的计算样式为 `display: none`，不能仅断言 DOM 的 `hidden` 属性存在。
6. To-do List 下显示页脚左侧图例；文档链接下隐藏页脚左侧图例；页脚右侧账号区域始终显示。
7. 两个 Tab 的 `aria-selected`、焦点顺序和左右方向键行为正确。
8. 登录页标题仍为“小胡同学To-do List”。

人工视觉验收包括：

- Tab 字号为 18px，两个 Tab 之间显示弱化的 `|` 分隔符。
- 色彩、边框、圆角、阴影和间距与当前深色界面协调一致。
- 切换过程中无明显布局跳动，公共页脚始终可用。
- 桌面宽度和现有窄屏断点下均无重叠或内容溢出。

## 非目标

- 不实现文档链接的新增、编辑、删除、分类、搜索或存储。
- 不记录用户最后选择的 Tab。
- 不修改登录页品牌文案。
- 不重构现有待办业务代码或后端接口。
