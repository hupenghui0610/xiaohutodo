# “小胡不当牛马”桌面品牌与图标设计

## 背景

应用已从单一待办工具扩展到待办、文档记录等功能，并将继续发展为个人工作台。现有桌面端仍以“小胡 Todo”显示，图标则使用日历、清单、深色圆角底板和青色外发光。旧图标能够说明待办功能，但信息较多，在 Windows 任务栏的小尺寸环境中显得复杂，也无法覆盖个人工作台的长期定位。

本次将用户可见的桌面品牌统一为“小胡不当牛马”，并用独立品牌符号替换功能插画式图标。

## 目标

- 桌面窗口、托盘、安装器和快捷方式统一显示“小胡不当牛马”。
- 新图标在 16、24、32 像素的 Windows 任务栏尺寸下仍有清晰轮廓。
- 图标使用透明外围，不增加圆角方形底板、外发光或复杂材质。
- 图标第一眼是轻盈的抽象几何标志，仔细看可以发现 H 的结构来源。
- 最终资源由确定性绘图流程生成，不直接使用 AI 生图中的随机边缘和渐变。

## 非目标

- 不重命名 `xiaohutodo` 包名、Cloudflare 项目、域名、数据库、Cookie、环境变量或其他技术标识。
- 不修改 `com.xiaohu.todo`，以避免破坏现有桌面安装和自动更新识别。
- 不借助图标表达待办、文档、工作台或“不当牛马”的具体含义。
- 不修改网页内容标题、登录页文案或飞书提醒标题；本次品牌更名范围仅为桌面壳和安装产物。
- 不引入动物、清单、文档、工作台、箭头、纸飞机或完整字母字体图形。

## 桌面名称

用户可见名称统一为精确文本“小胡不当牛马”，覆盖：

- Electron 主窗口标题。
- 托盘提示文本及下载更新时的托盘提示前缀。
- `package.json` 中的 `productName`、`shortcutName` 和桌面壳描述。
- Windows 安装器、开始菜单项目和桌面快捷方式名称。

内部包名、应用 ID、发布地址及存储键保持不变。

## 图标设计

### 核心造型

采用已确认的“斜切型双片 H”方向：

- 图标只由左右两个独立色块组成。
- 两个色块整体向右上倾斜约 6 度，形成轻盈、现代的运动趋势，但不承担具体语义。
- 每个色块的外侧为连续圆润曲线，内侧为短而克制的斜切凹口。
- 两个内侧凹口相对，中央负空间隐约构成 H 的横向连接；不能出现字体式、可直接输入的标准 H。
- 中央尖角应收钝并缩短，避免形成闪电符号。
- 两个色块不接触、不交叠，中央最窄处的透明间距不得小于图标视觉宽度的 6%，确保 16 像素下不会粘连。

### 比例与安全区

- 源画布为 1024 × 1024，背景透明。
- 图形视觉边界占画布宽度的 70%–74%、高度的 66%–72%。
- 图形四周至少保留画布宽度 13% 的透明安全区。
- 左片比右片宽约 6%，右片顶部比左片顶部低约 8%，通过轻微不对称避免普通双斜杠观感。
- 外轮廓圆角视觉半径约为单片宽度的 18%；内侧凹口圆角不超过单片宽度的 5%。

### 配色

仅使用两个不透明纯色：

- 左片：深紫蓝 `#5B4CF0`。
- 右片：淡紫蓝 `#8B7CFF`。

不得使用蓝青绿组合、渐变、透明叠色、阴影、高光、描边或外发光。透明度只用于画布背景。

### 小尺寸适配

1024 像素主图是几何源，但不同 ICO 尺寸应单独栅格化和检查：

- 256、128、64、48、32、24、16 像素全部写入 `build/app.ico`。
- 32 像素及以下允许对中央间距和内侧凹口进行像素级放大，优先保证分离和辨识度。
- 16 像素版本保留两个色块和中央缺口，不增加额外细节。
- `build/app-icon-preview.png` 使用 256 像素透明预览。
- 根目录 `icon.ico` 与桌面图标使用相同的视觉源，避免网页与桌面品牌分裂。

## 资源生成方式

`scripts/generate-desktop-icon.py` 继续作为图标资源的唯一生成入口。脚本使用高分辨率抗锯齿绘制两个确定性几何色块，再缩放到各目标尺寸。生成结果包括：

- `build/app.ico`：Electron 窗口、托盘和 Windows 安装器资源。
- `build/app-icon-preview.png`：人工视觉检查用预览。
- `icon.ico`：网页构建所复制的图标资源。

AI 生图只作为轮廓探索参考，不进入最终安装包，也不作为后续修改的源文件。

## 验证

### 自动检查

- 运行图标生成脚本后，确认三个输出文件存在且可读取。
- 使用 Pillow 读取 `build/app.ico`，确认包含 16、24、32、48、64、128、256 像素帧。
- 检查每个尺寸四角均为透明像素。
- 检查 16、24、32 像素版本中央仍存在透明分隔，两个色块未粘连。
- 搜索桌面壳和 `package.json`，确认用户可见的“小胡 Todo”均已替换为“小胡不当牛马”。
- 确认 `appId`、包名、URL、Cloudflare 名称、数据库名和 Cookie 名没有变化。

### 人工检查

- 在浅色和深色背景上查看 256 像素预览，确认无白边、黑边或颜色污染。
- 在 Windows 任务栏中检查 16、24、32 像素效果，与常用应用并排时不出现额外底板或光晕。
- 构建桌面安装包，确认窗口、托盘、桌面快捷方式、开始菜单和安装器均显示新名称与新图标。
- 若 Windows 图标缓存仍显示旧资源，应通过新构建产物或缓存刷新验证，不通过修改图标设计规避缓存问题。

## 验收标准

- 用户可见的桌面产品名称为“小胡不当牛马”。
- 图标为透明外围的紫蓝双色双片标志，无底板、渐变、阴影和外发光。
- 图标可隐约识别出 H，但不表现为普通字体字母。
- 16 像素下两个色块仍清楚分离，整体轮廓可辨。
- 桌面安装和更新身份保持兼容，现有技术标识不变。
