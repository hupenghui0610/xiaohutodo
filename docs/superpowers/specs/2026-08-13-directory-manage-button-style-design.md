# 目录管理按钮样式统一设计

## 目标

让文档链接页右上角的“目录管理”与 To-do List 页同位置的时间切换器保持一致的视觉语言，降低按钮默认状态的抢眼程度。

## 设计

- 使用深色半透明背景、深色描边、胶囊圆角和时间切换器同款轻阴影。
- 默认文字使用次级浅灰色，不再使用蓝色实底和发光阴影。
- 悬停时边框与文字变为浅蓝色，保留清晰的可点击反馈。
- 保留“目录管理”文字，不增加图标，不改变按钮位置、尺寸逻辑、显示条件或弹窗行为。
- 使用独立 `.directory-manage-btn` 类，仅影响该按钮。

## 验证

- 静态测试锁定独立类名、背景、边框、阴影和悬停反馈。
- 运行全量测试、语法检查与构建。
- 在线检查桌面端、375px 窄屏、按钮悬停及控制台。
