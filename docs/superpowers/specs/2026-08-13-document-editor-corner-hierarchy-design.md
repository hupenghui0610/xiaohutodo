# 文档编辑器圆角层级设计

## 目标

降低文档新增与编辑表单的胶囊感，用圆角大小表达容器、字段和操作的层级，同时不改变任何数据、校验或交互行为。

## 设计

- 编辑器外层容器沿用系统的 `10px` 中等圆角。
- 编辑器内的标题输入框、所属目录下拉框和描述框统一使用 `6px` 小圆角。
- 添加、保存等操作按钮继续使用 `999px` 胶囊圆角，以保留清晰的可点击识别。
- 取消按钮继续保持纯文字样式。
- 调整仅作用于 `.document-editor` 内的输入控件，不影响待办输入、登录框、目录管理或其他页面控件。
- 桌面端与移动端使用相同的圆角层级。

## 验证

- 静态测试锁定外框 `10px`、编辑器字段 `6px`、按钮 `999px`。
- 运行全量测试、语法检查和构建。
- 在线检查新增、编辑状态和 375px 窄屏，无溢出、无控制台错误。
