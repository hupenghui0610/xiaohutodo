# 列表长链接省略设计

## 目标

文档链接列表中，过长的网址只省略视觉文本，避免拉高或撑宽列表；链接后的普通描述文字仍完整展示。添加和编辑界面继续显示完整原文。

## 设计

- 仅对列表中的每个链接单独应用末尾省略，短链接不变。
- 链接最大可视宽度约为 `42ch`，同时不得超过当前描述列宽度。
- 完整 URL 继续保存在链接文本 DOM 与 `href` 中，不截断数据，不修改 API 或数据库。
- 链接保持可点击并在新标签页安全打开。
- 鼠标悬停通过原生提示显示完整 URL；键盘焦点样式保持可见。
- 链接后的标点、普通说明文字和其他链接均保持完整，并按现有规则自然换行。
- 编辑器 textarea 不应用省略样式。

## 验收

- 长链接在列表中显示末尾省略号，短链接完整显示。
- 同一描述内链接后的普通文字完整可见。
- 点击省略后的链接访问完整 URL。
- 添加或编辑时能看到并修改完整描述。
- 桌面和窄屏均无横向溢出。
